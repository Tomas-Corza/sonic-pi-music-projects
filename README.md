# Sonic Pi Music Projects

**Electronic music, creative coding, and live performance experiments by Tomas Corza**

Four electronic music compositions built with Sonic Pi and Ruby, exploring rhythmic sequencing, synthesis, layered arrangements, and algorithmic music.



## Tracks

| Script | BPM | Style and features |
| --- | ---: | --- |
| `tracks/01_intense_deep_tech_house.rb` | 126 | Deep/tech house with acid lead, arpeggios, pads, and live mixer controls |
| `tracks/02_dark_futuristic_house_g_sharp_minor.rb` | 124 | Dark futuristic house in G♯ minor, with layered bass, pads, and glitch textures |
| `tracks/03_techno_groove_140.rb` | 140 | Driving techno with distorted bass, synth stabs, and rhythmic sine-wave swells |
| `tracks/04_advanced_shoegaze_house.rb` | 120 | Shoegaze-inspired house with expansive chords and atmospheric layers |

## Running the music

1. Install [Sonic Pi](https://sonic-pi.net/).
2. Open any `.rb` file from the `tracks/` directory.
3. Paste the script into a Sonic Pi buffer and press **Run**.
4. Press **Stop** to end playback.

The scripts use Sonic Pi's built-in synths and samples, with no intentionally required third-party plugins or samples.

## Project background

These projects were developed during July and August 2026 as experiments blending electronic music production with programming. See [project notes](docs/PROVENANCE.md) for a breakdown of the creative ideas behind each track.
